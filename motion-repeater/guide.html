Motion Repeater

UI Array & Animation Toolkit · Version 1.0

Animate once. Repeat with intent.

Motion Repeater is an editor authoring tool for Unity UI motion design. Duplicate a source hierarchy into eight layouts, preview staggered motion, and bake repeated curves into a native AnimationClip. Generated arrays retain lightweight runtime controllers for parameters that remain animatable.

1. Installation and requirements

Import the package into Unity 6000.0.26f1 or a compatible Unity 6 project. The release was developed and validated on Windows with Unity 6000.0.26f1 and the Built-in Render Pipeline. Other editor versions, operating systems and render pipelines are not certified by this release.

Unity UI (com.unity.ugui, version 2.0.0 in the release project) is required. Install it from Unity's Package Manager if it is absent. The optional 2D Sprite package provides the Sprite Editor for creating sprite-sheet slices. Neither package is bundled or installed automatically. No paid third-party tool is required.

All supplied assets live under Assets/MotiLayer/MotionRepeater. Keep the Scripts folder outside an Editor folder: it contains runtime controllers as well as editor-only sections. The namespace is MotiLayer.MotionRepeater. The Examples subfolder contains the demonstration player, sprites, nine clips and one showcase scene.

Open Tools > MotiLayer > Motion Repeater. Open this guide with Tools > MotiLayer > Motion Repeater Manual.

2. Explore the nine examples

Open Examples/Scenes/MotionRepeaterShowcase.unity and enter Play mode. Choose any study from the left panel, or use Previous and Next. Pause freezes the animation; Restart returns it to the beginning. Playback loops with a short hold on the final pose.

The scene contains all nine original animation studies: Scale Echo, Grid Pulse, Nested Squares, Triangle Field, Color Wave, Type in Motion, Nested Ribbon, Year Cascade and Nested Type Field. These are creative examples of repeated and nested UI motion, not a one-to-one catalogue of the eight layout types. The original curves and generated hierarchies remain editable. The presentation hides offstage source objects while retaining them for inspection.

Eight native Unity Presets in Presets provide a starting configuration for each layout. The example player uses Unity's Playables API only; it is optional and can be omitted from a production build.

3. Build a static array

  1. Create a Canvas and a UI Image. Give the Image a unique, descriptive name.
  2. Assign the Image or its parent hierarchy to Source Object in Motion Repeater.
  3. Leave Animation Clip empty. Choose a layout and configure its count and dimensions.
  4. Start Preview. Adjust layout, clone overrides, index offsets and color/sprite settings.
  5. Choose Generate Array (No Animation). This keeps the generated hierarchy without writing animation curves.

Preview objects are temporary. Clear Preview removes them. Generate or Bake makes the result persistent. Keep the generated Item / Spacing / Offset hierarchy intact: it separates layout placement, index transforms and source animation so they can coexist.

4. Repeat and bake an animation

  1. Place the source beneath an object with an Animator, then create a writable AnimationClip for that root.
  2. Animate the source or any of its children in Unity's Animation window.
  3. Assign Source Object, Animation Clip and Animation Root in Motion Repeater. Animation Root is the Transform whose local paths the clip uses; it is usually the object with the Animator.
  4. Set Start Time and End Time in seconds. Existing keyframes on supported source and child curves within that interval are repeated. Choose bounds that include the required keys; the tool does not create new keys at interval boundaries. A zero-length interval repeats keys at that exact time.
  5. Set Stagger Frames and Playback Order. Start Preview and use the playback controls to inspect the result.
  6. Set Bake At in seconds and bake. Repeated curves are written into the assigned clip, starting at that time.

Use Animation Window copies its current clip and playhead time, resets the source interval to the full clip, and proposes the nearest Animator/Animation ancestor as the root. Verify this root when working with nested Animators. The tool uses public Unity APIs; selecting keys in Unity's Animation window does not select the source interval. Set the interval explicitly in Motion Repeater.

Bake writes to the assigned clip, so duplicate important clips before making experimental variations. Unrelated curves are retained. Successive bakes use unique group names and separate paths. Each bake and its generated hierarchy are grouped into one Undo operation.

Time Scale is a duration multiplier: 2 makes the source animation last twice as long; 0.5 makes it last half as long. Stagger Frames uses the assigned clip's frame rate. Playback Order controls timing ranks; Index Order independently controls how per-element transform and color changes are distributed.

5. Layout reference

Layout Main controls Timing and index options
Grid Rows, columns, X/Y spacing Sequential, random, from center, by row, by column
Ring Count, radius, start angle, spread, orientation Around the ring, random, paired expansion/convergence
Path Count, control points, linear/Bezier interpolation, spread, path alignment Along path, random, from center
Spiral Count, turns, inner/outer radius, winding, spread, orientation Along spiral, random
Radial Ray count, elements per ray, inner radius, radial spacing By ray, inner to outer, sweep around center, random
Hexagonal Outer rings, center-to-center spacing Ring by ring, by row, random, along hexagon
Scatter Count, random seed, rectangular width/height, reference point Random, distance from point
Sprite Shape Shape sprite, alpha threshold, sample rows/columns, width/height, spread By row, by column, from center, random

Layout-specific options appear automatically in the ordering panels. Reverse flips an order. A fixed random seed makes a random layout/order repeatable. Scatter does not enforce a minimum separation: overlapping elements are possible.

Spread is a normalized coverage control. Ring, path and spiral use 0-100% in the authoring panel. At 0%, elements overlap at the starting point; at 100%, they cover the full layout. Sprite Shape collapses to its center at 0%. Generated components may display the corresponding normalized 0-1 value where indicated. Grid, radial and hexagonal spacing are distances in local UI units.

Hexagonal arrays use concentric six-sided rings: one center element plus 6n elements in ring n. Total count is 1 + 3r(r+1), where r is the number of outer rings. Counts are 1, 7, 19 and 37 for zero through three rings.

6. Path editing and Bezier handles

Define the number of control points during setup. Insert points between existing points before generation. The generated ControlPoints hierarchy holds MotionRepeaterLinePoint components; animate their positions in the Animation window.

Choose Linear for straight segments or Bezier for a smooth curve. Advanced: Bezier Handles is collapsed by default. Automatic smoothing provides a quick starting path. Enable Manual Handles for explicit angle and length controls. Linked handles share angle and length on both sides by default; enable Independent Handles when a corner or asymmetric curve is needed.

Select a path array or control point to edit it in the Scene view: blue handles move positions; orange handles edit Bezier tangents. Record Control Point Keyframes writes the current values at the Animation window playhead. Open the correct clip on the array's Animator before recording. Keep point count fixed after generation; regenerate the array to change its topology.

7. Sprite Shape sampling

Assign a sprite whose opaque pixels define the desired silhouette. Sampling checks alpha at the center of each grid cell. Increase sample rows/columns for more detail, or lower Alpha Threshold if no valid cells remain. Match Sprite Aspect Ratio calculates the height from the source image.

The sampled point set is fixed when generated. Width, height and spread can be animated later. Changing the sprite, alpha threshold or sampling density requires regeneration. Sprite alpha sampling is an editor operation; generated runtime arrays do not repeatedly read the source texture.

8. Clone, index, color and sprite controls

Clone Overrides adjusts width, height, scale and Z rotation without editing the source. Index offsets distribute position, rotation and scale changes according to Index Order. Step applies a per-rank change; Total distributes a total change across the sequence. These controls can be combined with source animation because they act on separate hierarchy levels.

Color settings distribute a gradient over elements. Sprite settings distribute the slices of a Multiple-mode sprite sheet. Slice the texture in Unity's Sprite Editor first. A baked Color Controller can record gradient values as native Image.color keyframes, reconstruct a gradient from the current frame, or clear its color animation. Unity gradients support a maximum of eight color keys; denser samples are reduced to eight evenly spaced keys.

Color and sprite operations target Unity UI Image components. They are not a general material, SpriteRenderer or UI Toolkit styling system.

9. Nesting, Undo and Presets

An existing generated array can be the source for another array. Use one shared animation root above the source and destination. Relative paths preserve child animations, control-point curves and sprite-reference keys. Give siblings unique names and avoid '/' in object names, because Unity animation bindings use slash-delimited paths.

Undo/Redo covers authoring-panel settings, generated objects, supported component edits and clip-writing operations. Native Presets store reusable layout and effect settings. Presets deliberately exclude scene object references, clip/root/time selection and temporary preview/playback state.

Do not rename or reparent animated objects after baking without updating their bindings. Do not change baked element counts or delete required Item, Spacing, Offset or ControlPoints objects by hand. Regenerate instead. Array groups keep frozen timing/index mappings so component animation does not reorder elements unexpectedly.

10. Performance and limitations

Static controllers compare relevant state and skip unchanged layout calculations and Transform writes. Cached hierarchy references reduce repeated traversal. Animated parameters and control points invalidate the relevant state and update normally. Deep nesting still multiplies object and curve counts; use modest source hierarchies and test on the target device. This package is an authoring convenience, not GPU instancing or a particle system.

Supported data includes native float curves and object-reference curves within the source hierarchy. Animation events, Animator state machines, transitions, constraints, rigging and external effects are not duplicated as a retimed workflow. Root motion and humanoid retargeting are outside the intended UI use case. Bake into a writable .anim asset rather than an imported read-only model clip.

The tool is designed for RectTransform-based uGUI. The included example scene uses the Built-in Render Pipeline and Unity's legacy input module for its buttons. In projects configured for the new Input System only, replace StandaloneInputModule with InputSystemUIInputModule or enable both input backends. No Input System dependency is imposed by this package.

11. Troubleshooting

Only a static layout appears: assign a clip and its correct animation root, then check the source interval and source path. The interval must include keys belonging to the source or its descendants.

The bake button produces no animation: verify that the destination group and source are under the same animation root, the clip is writable, and names are unique. Read the status message in the tool.

Sprite Shape is empty: lower the alpha threshold, increase sample density, and verify that the sprite contains nontransparent pixels.

Sprite slices are missing: set Sprite Mode to Multiple and define slices. Assign the texture in Sprite settings.

Scene handles are missing: select a generated path array or control point. Enable Manual Handles to adjust Bezier tangents.

Demo buttons do not respond: enter Play mode, confirm an EventSystem is present, and use a compatible input module.

An animation stops working after reparenting: Unity bindings are relative paths. Restore the old hierarchy with Undo or rebuild the binding paths.

08 LAYOUTS

8 layouts, including paths and custom sprite shapes.

Rows, circles, paths, spirals, rays, hexagonal rings, seeded scatter or a shape sampled from a sprite. Each layout has its own placement and ordering controls.

Layout-specific order and stagger

Each layout offers ordering modes suited to its structure: by row or column, around a ring, along a path or spiral, by ray, across hexagonal rings, or by distance in a scatter. Choose from the modes available for that layout, reverse the order, and adjust stagger to build ripples, cascades and overlapping motion.

Independent playback, Index and color orders

Set playback order, Index order and Color & Sprite order independently. Playback order determines when each copy animates. Index order determines how offsets are assigned. Color & Sprite has its own distribution order, so the color pattern does not have to follow the animation sequence.

Position, rotation and scale with Index Offset

Apply position, rotation and scale offsets across the array using its Index order. Build stepped sizes, progressive rotations and shifted patterns. For a source with several parts, choose the transform targets that should receive the offsets during setup.

NESTED COMPOSITIONS

Nested arrays.

Repeat a ring, layer a grid or combine an inner pattern with an outer stagger. Build more elaborate motion from simple parts.

Ordinary GameObjects remain in the hierarchy, ready for the rest of your UI.

TWELVE EXAMPLES · ONE SCENE

12 animation examples.

Six nested compositions and six layout studies: Scale Echo, Grid Pulse, Nested Squares, Nested Ribbon, Year Cascade, Nested Type Field, Ring Bloom, Spiral Flow, Bezier Path, Radial Burst, Hexagon Rings and Luminance Portrait.

Paths and sprite shapes

Arrange your UI with Grid, Ring, Path, Spiral, Radial, Hexagonal, Scatter or Sprite Shape. Edit linear and Bezier paths with Scene-view handles, move elements along a path, or fill a custom sprite shape using alpha or luminance. Sprite sheets can animate the sampled shape; luminance can also vary element size or opacity.

Gradients and custom sprites on selected layers

Choose multiple target objects within your source and apply animated gradient changes, random colors and custom sprite variations to their Image components. Supply your own sliced sprite sheet to distribute its sprites across the array. Only Images on the selected objects are affected, so other parts of the source keep their appearance. Target selection is configured before generation.

Create and animate in Unity

Use spacing and other supported layout parameters to build the array, then keyframe those parameters on the generated components to animate the layout itself. A few progress controls let you manage the animation of many copies, including nested groups and gradient changes. Preview and adjust the result in Unity. Undo, native Unity Presets and header Reset are included.

Before you start

What does the package need?

Unity 6 and Unity UI. The release project uses Unity 6000.0.26f1 on Windows with the Built-in Render Pipeline. The showcase uses standard Unity UI materials. Other pipelines and platforms are not verified for this release.

What affects performance?

Copies remain GameObjects, and the Time Controller samples their source motion. Element count, nested hierarchy depth and animation complexity still affect runtime cost.

Can I convert an earlier array?

The scene migration command backs up the scene and clips, moves existing curves into composition clips and replaces them with Progress curves. Hand-edited motion is retained internally; it is not automatically reduced to a single shared source.

Which parts are fixed when I generate?

Element counts, path-point counts, selected targets and sprite sampling data. Regenerate the array to change them. Continuous layout parameters and Progress can be animated on the generated components.

What is outside the supported workflow?

Humanoid animation, root motion, Animation Events, additive Animator-layer blending and independent inner Animators writing the same properties as a Time Controller. This is a uGUI tool, not a 3D cloner, GPU instancer or UI Toolkit system.

Eight ways to repeat.

Each layout has its own spatial controls and ordering options. Playback order sets the timing; index order independently distributes transform and color changes.

01 / GRID

Rows and columns

Separate X/Y spacing with row, column, center-out and random ordering.

02 / RING

Around a center

Radius, start angle, coverage and orientation. Expand into a complete circle.

03 / PATH

Follow your curve

Linear or Bezier interpolation. Edit control points and tangent handles in the Scene view.

04 / SPIRAL

Turn outward

Set turns, inner and outer radius, winding direction, coverage and orientation.

05 / RADIAL

Build rays

Control ray count and radial spacing. Reveal by ray, radius or center sweep.

06 / HEXAGONAL

Grow ring by ring

Concentric hexagonal rings, beginning with one center element.

07 / SCATTER

Repeatable variation

Seeded placement inside a rectangular area, with distance-based ordering.

08 / SPRITE SHAPE

Fill a silhouette

Sample a sprite's alpha to turn opaque regions into an array of elements.

Before you start

Practical details, up front.

Compatibility and dependencies

Validated on Windows with Unity 6000.0.26f1 and the Built-in Render Pipeline. Requires Unity UI (uGUI 2.0.0). The optional 2D Sprite package provides sprite-sheet slicing. No paid plugin, online service or runtime AI account is required. Other editor versions, operating systems and render pipelines are not certified for this release.

What is included?

Eight layouts, complete C# source, eight native Unity Presets, nine animation clips, one interactive showcase scene, demo sprites and material, and an offline English HTML/Markdown user guide.

What stays animatable?

Supported controller parameters, path control-point positions and Bezier handles remain animatable after generation. Element counts, path-point counts and sprite-shape sample topology are fixed until regeneration.

What is outside the intended scope?

The workflow targets RectTransform-based uGUI. It is not a particle system, GPU instancing solution or UI Toolkit animation system. Scatter allows overlaps. Animation events, humanoid retargeting, root motion and state-machine retiming are not repeated by the bake workflow. Use an explicit time interval rather than native selected keys.

How was AI used?

OpenAI Codex assisted with implementation, refactoring, English localization, documentation, release automation and promotional composition. The publisher directed the workflows and supplied the original nine animation studies. Promotional screenshots and video show the included Unity scene.

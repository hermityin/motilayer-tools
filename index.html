BEFORE YOU START

Compatibility & requirements.

Unity and render pipelines

The package was uploaded using Unity 6000.0.26f1. This identifies the upload version, not a tested compatibility range. Most utilities edit project data rather than render it; particle previews and shader-property animation still depend on the assigned assets and shaders. Compatibility with every render pipeline or Unity version is not guaranteed.

Animation-window integration

Some animation tools use reflection to read internal Unity Editor state, including native keyframe selection. Unity updates can break this integration. Editor-only execution does not remove this compatibility or Asset Store review constraint.

Shader-property animation

MatKeyframer is one component for animating selected properties on UGUI Graphic materials, not a shader editor or material library. It creates material instances and runs in the player when used. Review batching and masking behavior with your own UI.

PSD workflow

PSD Importer requires a local Python 3.10+ installation with psd-tools and Pillow. Follow its PDF guide before first use.

Safe editing

Some actions rewrite Animation Clips or managed library folders. Start with duplicate assets, check the active clip and selection, and read the relevant guide before destructive operations.
